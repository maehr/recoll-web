# Security Policy

## Report a vulnerability

Report a security issue in private. Do not open a public issue.

1. Open a private report at <https://github.com/maehr/recoll-web/security/advisories/new>.
2. Describe the problem. Include the version or commit, and the steps to reproduce it.
3. Describe the effect. For example, state what an attacker can read or change.
4. Wait for a reply from the maintainer.

## Supported versions

recoll-web has no release yet. Until the first release, fixes go to the branch `main`.
After the first release, only the latest release gets security fixes.

## Scope

The README describes the protections of recoll-web and its known limits. Read its
[Security section](README.md#security) first.

Report an attack that works around a protection the README describes. Examples include an
attack that runs script in a page, or that changes the index. The README lists the known limits,
such as the lack of authentication.
